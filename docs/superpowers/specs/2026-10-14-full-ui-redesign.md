## 1. 设计原则

### 1.1 继承关系

| 来源 | 继承内容 |
| --- | --- |
| [2026-10-14 主题规范](2026-10-14-theme-constraints.md) | 唯一主题约束：明亮主题、黑白灰 + 主题橙、小范围成功 / 警告色、字号四级、间距、对比度、公共组件。10-08 / 10-10 / 10-12 三份旧文档的视觉规则均已被它取代 |
| 2026-10-13 报名表单设计稿（PR #206 已合入） | 三格步骤条、黑底信息条 + 左侧橙色短线、同级分区卡片（不套卡）、标签—值行 ≥ 44px、选中黑底白字、“默认”类标签灰底、按钮 88rpx、底部双按钮 0.82 / 1.18 |

### 1.2 原则

1. **可见即可操作**：所有输入框都有 2px 近黑描边；所有可点元素要么是按钮（主 / 次 / 文字三类），要么是带箭头的行，不允许“纯文字按钮”。
2. **橙色是信号，不是装饰**：橙色只出现在当前步骤、待处理（待审核数、必填未完成、错误描边）和焦点描边上。删除所有橙色圆环、渐变、曲线装饰、浅橙底计数。成功 / 警告色只用于小标签、行内提示和图标（主题规范 §3.3）。
3. **一个页面一套层级**：页面 = 导航栏 → （可选）步骤条 → 黑底信息条 → 同级分区卡片 → 底部固定栏。卡片内不再嵌套卡片，二级信息用标签—值行或数据格。
4. **状态完整**：每个列表页都必须设计加载、空、错误三种状态；每个表单都必须设计聚焦、错误、上传中、禁用状态。
5. **不恢复深色主题**；浅色下的对比度按主题规范 §6 逐项核对，不达标的组合禁止使用。

### 1.3 页面骨架

```text
导航栏（标题随模式变化）
├─ 步骤条（只用于填写报名）
├─ 黑底信息条（标题 / 时间 / 状态，左侧 4px 橙色短线）
├─ 分区卡片 01..n（2px 近黑描边，卡片间距 32rpx）
│   ├─ 卡片头：两位编号 + 标题 + 右侧标签
│   └─ 标签—值行 / 数据格 / 输入框 / 上传块
└─ 底部固定栏（提示 + 主次按钮，z-index 最高，预留安全区）
```

### 1.4 个人信息展示规则（用户已确认）

| 场景 | 实名 | 手机号 / 紧急联系人 | 昵称 |
| --- | --- | --- | --- |
| 本人页面（填写报名、报名详情、编辑资料、个人中心） | 完整 | 完整 | 显示 |

云端 cipher 加密存储不变，此规则只决定页面是否展示，不允许出现 `****` 脱敏。

### 1.5 文案

- 面向骑友与管理员的文字一律中文、口语化，不出现技术词（如“幂等入队”“RESULT / 1”）。
- 导航标题随模式切换：创建活动 / 编辑活动（“从此活动创建”生成的是草稿，进入后按编辑活动处理）；页内标题与导航标题一致（“审批详情”）。
- 计数统一“共 n 场 / 共 n 人”；字数计数按代码上限（如活动备注“26 / 5000”）。
- 不出现 Strava 授权、同步、解绑类文案（编辑页沿用代码说明“无需 Strava 授权；解析公开路线后会保存可信的路线详情。”）。
- 小程序不能跳转第三方：不出现打开 / 查看 / 跳转 Strava、第三方网页或 web-view 入口；Strava 路线只能复制链接。

## 3. 逐页说明

原型中每页右侧“截图问题 / 改版方案 / 对应规范”与本节一致，数据源为 `docs/schema.js`。

### 3.1 活动首页 `pages/activities/index`
- 问题：日期筛选、卡片橙描边与橙细线过多（G1、G6）；曲线装饰与“左右滑动切换”提示；数据格与详情页不一致（G2）。
- 方案：日期筛选改双行票据标签（§2.8），选中黑底白字；名额剩余较少的活动卡加 warning 小标签“⚠ 名额紧张”；“即将开始 / 历史活动”分段控件；列表头“共 n 场”；活动卡 = 16:9 封面 + 状态徽标 + 标题 + 集合信息 + 三格数据（里程 / 爬升 / 名额）+ “报名活动”主按钮；无封面时品牌化黑底。补加载 / 空 / 失败。
- 状态：有活动、空状态、加载中、加载失败。

### 3.2 活动详情 `pages/activity-detail/index`
- 问题：B1 路线图压按钮栏；B2 海拔折行、顶部数据截断；B3 层级平铺；B4 浅橙角标、写死颜色。
- 方案：层级为 封面（1/3 计数）→ 黑底信息条（日期 / 标题 / 集合 / 状态）→ 2×2 指标 → 报名状态卡 → 集合信息卡（地图导航次按钮）→ Strava 复制卡 → GPX 卡（数据格 + 路线轮廓 + 海拔曲线静态图 + 下载 GPX）→ 已报名人员（只显示昵称）→ 活动群二维码 → 备注。
- **Strava 复制卡**：标题“Strava 官方路线” + “官方”灰标签 + 说明“复制组织者分享的规范化公开路线链接。”；只有一个“复制路线链接”次按钮（对应代码 `copyOfficialRoute` → `wx.setClipboardData`），下方提示“小程序内不打开第三方页面，复制后可自行粘贴使用。”。不提供打开、查看、跳转 Strava 或 web-view 入口。
- **复制反馈**：复制按钮下方行内提示——成功为 success 样式“✓ 路线链接已复制”，失败为白底 2px 橙描边 + 橙色“!”近黑字“复制失败，请稍后重试”；同时弹 toast（成功白色 ✓，失败橙色 !），2s 自动消失，不改变卡片布局。
- **提醒与状态**：报名状态卡“已通过”用 success 标签；未报名时卡内加 warning 小标签“⚠ 即将截止 · 10月17日 20:00”；黑底信息条徽标统一灰描边（报名中不再用橙）。
- 底部固定栏为单主按钮（代码 `activityAction`）：立即报名 / 查看我的行程 / 名额已满（禁用）；z-index 最高。
- 状态：已通过、未报名、名额已满（主按钮禁用）、路线链接已复制、复制失败。

### 3.3 填写报名 `pages/registration-form/index`（基准页，PR #206 已实现）
- 保持 2026-10-13 设计稿：三格步骤条、黑底活动信息条、四张同级分区卡片（01 报名资料 / 02 集合方式 / 03 能力确认 / 04 备注与安全）、标签—值行（本人完整实名与电话）。
- 02 卡提示按代码：“名额以提交时状态为准；活动或所选方式满额后，将自动进入候补。”；03 能力确认三选一（新手 / 有经验 / 常骑），未选时提交禁用；不展示后援车司机。
- 底栏“返回活动 / 提交报名”0.82 / 1.18 + “还差 1 项”提示。
- 状态：未选择（提交禁用）、已选择、提交中。

### 3.4 我的行程 `pages/registrations/index`
- 问题：统计条字号、橙色数字与卡片描边不统一（G3）；状态不识别未通过 / 候补（G8）。
- 方案：黑底三格统计条（审核中 / 可出发 / 已失效，与代码一致），只有审核中 > 0 时出现橙点；票据行程卡 = 状态徽标 + 日期 → 标题 → 黑底集合信息 → 查看凭证次按钮；状态映射见 §2.9（已通过为 success 标签）。
- 状态：有行程、空状态（引导去活动首页）、加载中。

### 3.5 报名详情 / 出发凭证 `pages/credential/index`
- 问题：C1 无背景图名片空状态简陋；C2 导航按钮文字不居中；C3 与报名表单风格不统一。
- 方案（按代码结构）：票据凭证 = 品牌头 + 凭证编号 → “✓ 已通过 · 准时集合”success 徽标 + 标题 → 黑底集合信息条（集合时间 24px、地点、地址、地图导航反白按钮）→ 标签—值行（骑手 / 性别 / 集合方式）→ 队伍卡（队长可分享邀请）→ “取消报名”次按钮（二次确认）；下方“公开骑行名片”。不加步骤条、不放签到二维码、不展示司机。
- 活动关闭后显示“活动报名已关闭，当前记录仅供历史查看。”
- 状态：名片有背景图、名片无背景图。

### 3.10 活动管理 `pages/admin/activity-list/index`
- 问题：F1 卡片信息太少；F2 橙色圆环与渐变；F3 筛选整块橙底；F4 缺空 / 加载；F5 “从此活动创建”需手填 ISO 时间。
- 方案：头部 = 标题“我的活动” + 说明；分段筛选“全部 / 已下架 / 已上线 / 已结束”；管理卡 = 状态徽标 + 日期时间 → 标题 → 三格数据（报名 / 待审核 / 已通过）→ “编辑 / 上架或下架”小号次按钮 + “删除（仅草稿）”“从此活动创建”文字按钮；列表下方“报名审批”次按钮 + “创建活动草稿”主按钮。“从此活动创建”弹层用报名截止 / 开始 / 结束三组日期 + 时间选择器（默认带入原时间），按钮“取消 / 创建草稿”。

### 3.11 创建 / 编辑活动 `pages/admin/activity-edit/index`（最严重）
- 问题：A1–A8，见 §4。
- 方案：3 张同级分区卡片（与代码一致）01 基本信息 / 02 活动封面 / 03 备注、路线与群二维码；全部输入框 2px 描边；日期、时间为选择器；“地图选点”为输入框右侧次按钮；封面三格缩略图 + “封面”灰标签 + 灰底“1 / 3”；备注计数“/ 5000”。

- 状态：编辑活动、创建活动（空）、校验错误（标题 / 集合点橙描边 + 底栏“还有 2 项必填未完成”）、上传中。
