# 此里浅暗主题可读性优化

用户已于 2026-11-03 确认前轮主题建议并要求同时注意暗色主题。本方案在最新 `origin/main@67244eec` 的 AI Hero、17 页公共主题接缝和设置页浅暗切换上实施。

## 范围与目标

浅色采用暖白页面、白色内容、近黑主文字和经典红动作。暗色保留电影深色画布、浅色正文、独立媒体遮罩和真实状态。两种主题共同减少装饰灰线、卡片套框及指标竖线；使用无衬线业务标题、较大正文和辅助字，等宽字体集中于数字。

业务字段、权限、状态、路由和主题切换方式沿用现状。历史 `2026-10-22-cycling-image-journal` 设计 snapshot 保留；正式 Pages 作为当前运行 UI 的同步镜像调整。

## 实现规则

- `miniprogram/config/appearance.ts` 管理双主题语义覆盖；正式 Pages 对应镜像保持同值。
- 装饰分隔使用 subtle/border，输入和次按钮使用 strong，普通内容容器使用背景与间距。必要控件边界与邻接表面对比至少 3:1。
- 正文、辅助、placeholder、状态文案在实际表面至少 4.5:1。媒体文字、遮罩和二维码独立，不随浅色反色。
- 业务正文优先 32rpx，辅助信息优先 28rpx；少量短索引可保留 24rpx。保持已有 44px 实际触控下限。
- 标题使用正文无衬线；自然语言标签和字段值使用正文，无意义编号装饰减少。数字与凭证序列保留等宽语义。
- 三列距离、爬升、时间布局保持；移除外框及竖线，增加列间距和标签字号，保留完整单位。
- 连续阅读章节以纵向留白分组；移除额外标题横线。固定操作栏、上传和输入保留必要结构与状态。
