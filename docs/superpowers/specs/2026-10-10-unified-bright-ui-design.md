# 全局统一明亮 UI 设计

## 背景与目标

`HP-20261010-02` 已确认取消旧版布局及深浅主题分叉。第一批覆盖活动首页、活动详情、创建活动、我的行程、个人中心和设置，同时把全局系统外观、共享 token 与公共组件收敛为唯一来源。

目标不是制作静态效果页，而是在不改变真实业务流程、分页、授权、保存、异常恢复和无障碍语义的前提下，统一为适合户外阅读的明亮高对比界面。

## 方案选择

采用分层迁移：

1. 单一主题底座：固定白色系统外观，删除持久化主题选择、页面 `themeClass` 状态和双主题选择器。
2. 共享视觉组件：统一品牌头、按钮、输入、卡片、状态、活动卡和固定操作区。
3. 第一批六页：只调整信息层级、模板结构和样式，不改领域数据流。
4. 后续页面：先依赖统一 token 维持可读，再在下一批逐页精修。

未采用的方案：

- 全量 14 页一次性重写：回归面过大，无法以小批次证明业务行为保持不变。
- 仅在现有样式末尾覆盖：会继续保留 `theme-dark/theme-light`、运行时切换和大量暗色硬编码，无法满足“移除旧主题体系”。

## 视觉系统

### 画布与布局

- 基准画布：375×812px。
- 页面边距：16px，即 `32rpx`。
- 基础栅格：8px，即 `16rpx`。
- TabBar：56px 加安全区；Tab 页不得被遮挡。
- 主按钮、输入和主要触控区：最小 48px，即 `96rpx`。
- 分段控件：40px，即 `80rpx`。
- 卡片内边距与圆角：16px，即 `32rpx`；卡片间距 12px，即 `24rpx`。

### 色彩与形态

- 主背景 `#ffffff`，次级背景 `#f4f5f0`，正文 `#10120f`，辅助文字 `#5b6258`。
- 品牌色采用荧光黄绿色 `#d9ff43`，品牌文字始终使用近黑色。
- 卡片和输入使用 2px 近黑描边；关键卡片可使用 4px 硬阴影，不使用柔和漂浮阴影。
- 媒体上的文字继续使用白色和不透明深色遮罩，不能因全局明亮主题降低可读性。
- 成功、警告、危险状态保留独立语义色，不把品牌色当作所有状态色。

### 字体层级

- 页面标题 24/32px。
- 卡片标题 18/26px。
- 正文 14/22px。
- 辅助文字 12/18px。
- 不使用随视口变化的字号；字距保持 0，品牌短标识除外。

## 系统外观与主题清理

- `app.json` 和全部页面配置固定白色导航、黑色前景、白色滚动边界和深色下拉反馈。
- `theme-service.ts` 收敛为幂等的 `applyAppAppearance`，只负责容错调用系统导航、TabBar 和背景 API。
- 页面不再保存 `theme`、`themeClass`，根节点不再拼接主题类，`onShow` 不再同步主题。
- 设置页删除“外观偏好”和切换处理函数。
- TabBar 固定使用适配白底的未选中图标和品牌色选中图标。
- 删除 `.theme-light`、`.theme-dark` 选择器和仅服务主题切换的测试；保留语义 token。

## 第一批页面

### 活动首页

保留未来/历史筛选、刷新、分页和活动卡打开行为。顶部压缩为品牌栏、24px 标题和 40px 分段控件；活动卡使用真实封面或清晰占位面，正文数据放在白底描边区域。

### 活动详情

封面继续作为首屏主视觉，所有真实路线操作、海拔图、骑友卡、CTA 和空态保持。关键指标落在白底描边三列中，内容卡统一 16px 圆角，固定报名操作区使用白底和安全区。

### 创建活动

实际页面为 `pages/admin/activity-edit`。保留日常/精品局、图片、时间快捷项、地图、Strava、校验定位和发布状态。双列字段在 375px 下改为单列，避免小屏触控拥挤；模式选择使用明确的单选卡。

### 我的行程

保留全部历史加载和凭证跳转。卡片使用状态色侧边标识、近黑标题和可读的 `RIDE N` 序号，确保普通文字对比度不低于 4.5:1。

### 个人中心

保留照片主视觉、下拉刷新、缓存、身份、Strava 能力和管理入口。照片区域继续使用媒体色；其余内容回到白色主背景和描边结构，设置入口改为图标按钮并保留可访问名称。

### 设置

删除主题选择，Strava 管理前置，升级日志后置。新增本次统一 UI 版本日志并保持历史记录不改写。

## 行为与错误处理

- 不改变任何 service、repository、云函数协议和领域状态机。
- 图片失败、迟到响应、页面卸载、授权失败和保存失败继续使用现有降级。
- 系统外观 API 缺失或抛错不能阻断启动。
- 所有 loading/error/empty 状态继续由真实状态驱动。

## 测试与验收

1. 静态契约先失败：禁止主题类、主题存储、设置切换入口和暗色系统配置；锁定 token、尺寸和六页关键结构。
2. 页面单测：设置页 Strava 与升级日志继续通过；六页既有业务测试不得因视觉迁移失效。
3. 全量门禁：格式、lint、类型、前端测试、云函数测试、覆盖率和构建全部通过。
4. 运行态：375×812 逐页截图，检查边距、标题、卡片、48px 触控区、56px TabBar、安全区、文本截断和无重叠。
5. 发布：main CI、微信开发版上传和真机截图均有独立证据后，才能关闭条目。
