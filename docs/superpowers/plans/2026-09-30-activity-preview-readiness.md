# Activity Preview Publishing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow a complete event announcement to be published before registration operations are configured, while keeping registration fail-closed and preserving later editing.

**Architecture:** Keep `status` as the publication lifecycle and derive registration readiness from one shared server function. Public and admin DTOs preserve optional operational fields; clients render incomplete registration as “报名待开放”. Updates merge omitted operational fields from the current record so only explicit zeroing clears driver data.

**Tech Stack:** WeChat Mini Program TypeScript/WXML/WXSS, CloudBase Node.js 20 functions, Vitest, Node test runner.
