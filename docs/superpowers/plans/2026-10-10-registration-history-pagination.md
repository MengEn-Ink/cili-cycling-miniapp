# Registration History Pagination Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make “我的行程” return every registration and safely preserve finished, unpublished, deleted, and missing activities without depending on the public activity list.

**Architecture:** Add a backward-compatible `minePage` action with an opaque `created_at + _id` keyset cursor while retaining legacy `mine`. `CloudRepository.listRegistrations()` consumes every strict page behind its existing array interface, and the page renders only the owner-bound activity projection. Missing activities can still be cancelled without attempting to mutate a nonexistent capacity record.

**Tech Stack:** Node.js Cloud Functions, CloudBase database queries and indexes, TypeScript, WeChat Mini Program page runtime, Node test runner, Vitest.

- [ ] **Step 1: Implement strict cursor parsing**

Use versioned base64url JSON with exact keys:

```js
{ v: 1, created_at: '2026-10-10T00:00:00.000Z', id: 'registration-id' }
```

`parseMinePageRequest(event)` must return `{ pageSize, boundary }`, default to 50, reject unknown shapes, noncanonical dates, IDs outside 1-128 bytes, and cursors longer than 512 characters.

- [ ] **Step 2: Implement keyset query**

Build the owner-bound condition:

```js
command.and(
  { openid },
  command.or(
    { created_at: command.lt(boundary.createdAt) },
    command.and(
      { created_at: command.eq(boundary.createdAt) },
      { _id: command.lt(boundary.id) },
    ),
  ),
);
```

Query with:

```js
db.collection('registrations')
  .where(condition)
  .orderBy('created_at', 'desc')
  .orderBy('_id', 'desc')
  .limit(pageSize + 1)
  .get();
```

Return raw `{ items, next_cursor }`, where the cursor is built from the last included item only when an extra item exists.

- [ ] **Step 3: Add `minePage` and harden activity downgrade**

In `registration/index.js`, keep legacy `mine` unchanged and add:

```js
  return ok({
    items: await withActivities(page.items),
    next_cursor: page.next_cursor,
  });
}
```

Treat the activity as unavailable when it is absent, `draft`, or `is_deleted === true`. Preserve safe title/time fields, force `status: 'finished'`, and pass the result through `publicActivity`.

### Task 5: Implement Client Aggregation and Page Independence GREEN

**Files:**

- [ ] **Step 1: Implement strict repository paging**

Add a strict page mapper requiring exact `items` and `next_cursor` keys. In `listRegistrations()`:

```ts
const items: Registration[] = [];
const ids = new Set<string>();
let cursor: string | undefined;
for (let page = 0; page < 200; page += 1) {
  const response = await this.call('registration', {
    action: 'minePage',
    page_size: 50,
    ...(cursor ? { cursor } : {}),
  });
  const mapped = mapRegistrationPage(response);
  for (const item of mapped.items) {
    if (ids.has(item.id)) return invalidResponse();
    ids.add(item.id);
    items.push(item);
  }
  if (mapped.nextCursor === null) return items;
  if (mapped.nextCursor === cursor) return invalidResponse();
  cursor = mapped.nextCursor;
}
return invalidResponse();
```
