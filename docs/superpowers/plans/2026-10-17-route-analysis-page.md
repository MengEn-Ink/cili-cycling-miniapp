> 状态：设计定稿、待前端还原；本轮只更新 `docs/` 静态原型与设计稿，不改动 `miniprogram/` 产品代码。
> 范围：活动详情"路线概览"摘要 + 完整路线分析页；两处作为同一条线性信息架构处理。

## 1. 背景与问题

### 1.1 用户反馈回顾

- **IMG_3006 / IMG_3007** – 活动详情"GPX 路线详情"卡与底部固定报名栏之间互相挤压：
  - 路线部分表达稀薄（只有一张轮廓缩略 + 一行说明），信息密度低到不足以支撑"出发前看一眼"。
  - 滚到底部时，固定的"立即报名"按钮遮挡了路线说明末尾与报名倒计时，用户必须手动继续下滑才能看全。
- **IMG_3008 / IMG_3009** – 完整路线分析页：
  - 页面层次是"卡套卡"，视觉中心全部给了"外部增强能力状态""数据来源与质量"等**技术性**说明；"实时天气未接入""交通事件待开通""地点名称待接入逆地理编码""坐标复制"等技术痕迹反而排在用户真正想看的指标与关键点之前。
  - 大段标题 + 大段正文 + 零散指标行，让一个本应像**专业骑行码表 / 路线手册**的页面读起来像"系统状态报告"。

### 1.2 本次设计的核心判断

1. **活动详情**是"决策是否报名"的入口页，路线信息只需要摘要 + 一个强入口；完整路线应移到独立页。
2. **route-analysis**是一个高密度专业页面，可以、也应该在视觉上明显区别于其他沸点风格页面——它是全站唯一的"骑行码表 / 路线手册"。
3. **未接入 = 不展示**。所有"TODO / 未接入 / 数据边界 / 技术来源"类技术痕迹，不出现在用户可见界面。能力就绪后再上线占位。

### 1.3 V2+ 追加覆盖（本轮）

在 V2 基础上继续扩展**完整路线分析**页的内容密度，覆盖 5 个新诉求（活动详情页仍只保留摘要入口，不受本节影响）：

| 诉求 | 本轮承载模块 |
| --- | --- |
| **骑行走向**（按公里分段的方位、道路、地形、关键转向、危险下降） | 新增"骑行走向"面板 |
| **爬升变化**（在总览外，列出爬升段 / 下降段的坡长、Δm、平均/最大坡度、趋势、最高点） | 新增"爬升与下降"面板 |
| **关键地名备注**（每个关键公里点显示地名、km、海拔、经纬度、用途/注意事项） | 升级"关键公里点"面板，每行追加经纬度 + 用途 + 注意事项 |
| **补给方案**（补水/能量/正餐节奏 + 建议补给点 + 到达 km 和预计时间 + 携带下限） | 升级"补给方案"面板（节奏表 + 补给点卡 + 携带下限） |
| **卫生间坐标**（名称、经纬度、距路线偏离、开放备注；地图独立图例和标记） | 新增"沿线卫生间"面板 + 地图 WC 标记 + 底部图例 |

全部新内容遵循第 4A 节"真实数据展示规则"：有真实验证数据才展示，字段缺失走字段级隐藏，整模块无数据走整模块隐藏，**不得伪造**。

## 2. 目标与非目标

### 2.1 目标

- **G1**：活动详情只保留**路线概览摘要**（≤ 1 屏模块高度）+ **"查看完整路线分析"CTA**；修复底部固定栏遮挡。
- **G2**：完整路线分析页按**码表 / 路线手册**风格重做，首屏即可读到：地图 + 四项核心指标 + 海拔曲线。
- **G3**：地图 / 海拔 / 关键点 / 坡段四者**可观察联动**；选中态在页面各模块以同一视觉语言表达。
- **G4**：对未接入能力整体隐藏（天气、交通、逆地理编码、GPX 下载入口等），不显示技术占位。
- **G5**：375 × 812 与 390 × 844 下**无横向溢出**；底部按安全区留白；一级可点元素 ≥ 44 × 44。

### 2.2 非目标

- 不改动小程序业务逻辑、派生规则、云函数、路线事实源契约。
- 不新增外部服务接入；只是把"未接入"的 UI 位撤出。
- 不实现实时导航 / 定位回放 / Canvas 拖动。

## 3. 高密度特殊页面豁免

`route-analysis` 作为**全站唯一**的高密度路线手册页面，经评审豁免以下**全局沸点主题**装饰门禁，但仍严格遵守可读性 / 触控 / 安全区底线：

| 维度 | 全局沸点主题 | route-analysis 豁免 | 底线 |
| --- | --- | --- | --- |
| 页面底色 | `--color-bg` 米黄 | 可切换为暖白 `#fbf5ea` | 需与深炭字对比度 ≥ 7:1 |
| 主色 | `--color-brand` 深橙 | 可引入功能色：地图青绿 `#0f766e`、海拔橙红 `#d64520`、路段黄 `#d4a017` | 功能色只用于**信息编码**，不做大面积装饰底 |
| 卡片 | `.card` 圆角 + 分页边距 | 可使用更紧凑的 `.ra-panel`，分段间距 ≤ 12px | 面板之间仍需 1px 边界或色差，避免信息糊成一块 |
| 字号层级 | 全站 H3 / sub-title | 可下探到 10–11px 的码表式 label | 正文 ≥ 12px；主要指标 ≥ 18px |
| 盒子装饰 | 弱描边 + 浅底 | 可使用 1 条品牌色强边条（如 3px `#d64520` 左边条） | 不使用阴影 / 渐变装饰 / 玻璃拟态 |
| 内联 hex | 必须来自 `:root` 变量 | 页面范围内可内联功能色 hex | 合同测试已登记豁免色列表；新增需同步 |

**豁免只覆盖 `route-analysis` 与活动详情的 `.route-brief-card`**。其他页面继续走沸点主题。

## 4A. 真实数据展示规则（V2+ 扩展）

本页生产数据中的具名地名 / POI / 坐标 / 时间都必须来自主办方录入或已验证的离线地理库，**不得伪造**。当前静态原型使用脱敏演示样本，仅用于评审信息形态，不代表目标活动的真实路线事实；产品上线前后统一遵守以下规则。

### 4A.1 字段源与验证要求

| 模块 | 字段 | 来源 | 验证要求 |
| --- | --- | --- | --- |
| 关键公里点 | 地名 label | 主办方录入 | 必填 + 非系统性占位（如"位置 1"不算） |
| 关键公里点 | lat / lng | GPX / 主办方录入 | 必填，与路线轮廓最近点距离 ≤ 100 m |
| 关键公里点 | role 用途 | 枚举（起点 / 补给 / 最高点 / 下坡起点 / 终点 等） | 必填 |
| 关键公里点 | caution 注意 | 主办方录入 | 可选，字段级隐藏 |
| 骑行走向 | 每段 km 范围 | 剖面派生 | 必填 |
| 骑行走向 | 方位 / 道路 / 地形 | 主办方录入 + 离线地图 | 任意两项为空该段隐藏 |
| 骑行走向 | 关键转向 / 注意 | 主办方录入 | 可选，字段级隐藏 |
| 爬升与下降 | km 范围 / 坡长 / Δm / 平均坡度 / 最大坡度 / 趋势 | 剖面派生 | 全部由派生规则产生，无需外部数据 |
| 爬升与下降 | 最高点卡片 | 剖面派生 + 关键点关联 | 若关键点中有 `highest` 时展示 |
| 补给方案 - 节奏 | 补水 / 能量 / 正餐 | 产品固定建议 | 固定文案，不依赖主办方 |
| 补给方案 - 补给点 | km / 名称 / 类型 | 关键点中 `role` 含"补给" | 从关键点派生 |
| 补给方案 - ETA | hh:mm | 主办方开始时间 + 距离 / 平均速度派生 | 需要主办方录入开始时间，否则该列隐藏 |
| 补给方案 - 携带下限 | 列表 | 产品固定建议 | 固定文案 |
| 沿线卫生间 | 名称 / lat / lng | 主办方录入或 OSM 验证点 | 必填 |
| 沿线卫生间 | 偏离主路距离 | lat/lng 对路线的最近点距离 | 必填（派生） |
| 沿线卫生间 | 开放备注 | 主办方录入 | 必填（含"全天 / 时段 / 需索取钥匙"等） |

### 4A.2 字段级隐藏与整模块隐藏

- **字段级隐藏**：单条内任一可选字段（如 caution / 关键转向 / ETA）缺失时，仅该字段不渲染，不以"—"或"未设置"占位。
- **整模块隐藏**：某模块所需的必填字段完全缺失（例如没有任何已验证真实卫生间 POI），**整个模块不渲染**，不展示空面板，也不展示"暂无数据"占位。
- **绝不伪造**：不得为补齐展示而编造地名、坐标、开放时段、ETA；上线前检查工具会扫描关键点与卫生间列表中的占位串（如"位置 1 / TBD / 待定 / 00:00"）并拒绝发布。

## 5. 视觉语言

- **底色**：`#fbf5ea` 暖白（页面）+ `#ffffff` 面板。
- **主字**：`#211f1c` 深炭，常用 800–900 字重以呼应码表风格。
- **次字**：`#6f675d` 砂灰。
- **功能色**：
  - 地图青绿 `#0f766e`：起点、补给点 km、"✓"等肯定态。
  - 海拔橙红 `#d64520`：面板头强边条、最高点、当前关键点、海拔线色。
  - 路段黄 `#d4a017`：风险提示左边条。
- **分段难度**：
  - 轻松 `#e4ede8` 底 / `#185a4a` 字。
  - 适中 `#f8ecc9` 底 / `#7a5a0f` 字。
  - 挑战 `#fbe0d8` 底 / `#a52a1c` 字。
- **数字排版**：所有数值使用 `font-variant-numeric: tabular-nums` 对齐。
- **选中态**：面板内用 `#fff8ec` 行底 + `#211f1c` 粗边 / shadow；跨面板用 color-swatch + caption 文字呼应。

**不使用**：卡套卡、巨型标题、大面积留白、阴影 / 渐变 / 玻璃拟态、品牌橙按钮。
