## 状态定义

- `待处理`：已确认问题，尚未开始。
- `处理中`：已有负责人或正在执行。
- `待部署`：代码与测试完成，尚未部署目标环境。
- `待验收`：已部署，等待真实环境验证。
- `阻塞`：缺少权限、环境、产品决策或外部依赖。

## Agent 执行规则

1. 开始任何项目任务前先阅读本文件，优先处理 `P0`，再处理 `P1`。
2. 不得跳过正在阻塞交付的高优问题去做低优美化；若必须调整顺序，要在表内写明原因。
3. 新问题必须先去重，再拆成可验证的单一条目，并填写优先级、状态、进度、下一步和完成标准。
4. 每次提交、部署或验收后立即更新对应条目；只完成代码但未部署时，状态最多为 `待部署`。
5. 已部署且验收通过的条目从本文件删除，不保留“已完成”列表；历史通过 Git 提交追溯。
6. 若任务会修改代码，仍须遵循仓库测试、覆盖率、安全审计、单提交和 PR/部署门禁。
