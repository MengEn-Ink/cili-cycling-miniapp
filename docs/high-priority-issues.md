## 口径

- `*.test.ts` / `*.node-test.*` 是 Mock 或契约测试，不是真实 E2E。
- Pages 与 UI sync 是原型和同步证据，不是 IDE、云端写链路或真机证据。
- DevTools 只能证明对应 SHA、账号和环境的只读运行，不能当作物理真机。
- 未在当前 SHA 执行的事项必须记为 `BLOCKED` 或 `NOT_EXECUTED`；历史真实运行不得重标为当前版本。
