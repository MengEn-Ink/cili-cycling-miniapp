- 所有工作从最新 `origin/main` 创建 `feat/`、`fix/`、`chore/` 或 `docs/` 分支，禁止直接提交 `main`，禁止使用含 `aime` 的分支名。

- PR 合并后删除来源分支；已合并但残留的远端分支仅在确认无开放 PR、无独立提交后清理。
