# CILI Logo 使用规范

## 1. 标志构成

CILI 标志由“路线环图标”和自有等宽字标组成。路线环保留圆角端点，表达路线、同行和持续向前；字标已转为路径，任何平台不得替换字体或重新排字。

- 标准横版：图标 + `CILI`，用于有充足横向空间的品牌露出。
- 图标版：仅路线环图标，用于头像、Favicon、底部栏和紧凑控件。
- 竖版：图标在上、字标在下，用于接近方形的版面。
- 单色版：仅在单色印刷、雕刻或无法使用品牌红时使用。

## 2. 比例与安全区

设图标边长为 `X`：

- 横版图标与字标间距固定为 `0.20X`。
- 字标可视宽度约为 `1.25X`，不得单独拉宽或压窄。
- 标志四周至少保留 `0.25X` 安全区；安全区内不得放置文字、边框、裁切线或其他标志。
- 图标圆角、路线环笔画和字标必须整体等比缩放。

## 3. 响应式规则

| 可用宽度 | 使用方式 |
| --- | --- |
| `≥ 120 px` | 展示完整横版标志 |
| `24–119 px` | 仅展示路线环图标 |
| `16–23 px` | 仅用于 Favicon 等不可避免的小尺寸场景 |
| `< 16 px` | 不展示 Logo |

数字端完整横版建议宽度不小于 120 px，独立图标建议不小于 24 px；印刷端完整横版建议宽度不小于 32 mm，独立图标建议不小于 6 mm。

## 4. 背景与配色

- 深色背景使用品牌红图标 + 白色路线环 + 白色字标。
- 暖纸或浅色背景使用品牌红图标 + 白色路线环 + Cinema Ink 字标。
- 复杂照片上优先使用带半透明 Cinema Ink 承托的水印稿。
- 单色黑稿用于浅色背景；单色白稿用于深色背景。
- 不使用渐变、投影、描边、透明品牌红或未经令牌定义的相近红色。

## 5. 动效

加载动画由 8 帧组成，每帧约 110 ms，完整循环约 880 ms。动点只能围绕中心标志旋转，Logo 本体保持稳定。系统启用“减少动态效果”时，使用 `loading-00.png` 静态帧。

## 6. 禁用规则

- 禁止改变图标与字标的相对比例或间距。
- 禁止旋转、倾斜、镜像或非等比缩放。
- 禁止把路线环替换成系统字母、字体字符或表情符号。
- 禁止在低对比度背景上直接使用透明稿。
- 禁止把完整横版硬塞入狭窄空间；空间不足时必须切换图标版。
- 禁止裁切圆角方章、给方章再次套圆角遮罩，或在图标内部添加文字。
- 禁止从截图或小尺寸 PNG 反向制作大图。

## 7. 交付与校验

所有正式物料必须能在 `manifest.json` 中找到对应记录，并核对尺寸、用途与 SHA-256。SVG 是可编辑事实源；PNG、GIF、ICO 和 PDF 都由生成器派生，不在导出文件上做二次编辑。
