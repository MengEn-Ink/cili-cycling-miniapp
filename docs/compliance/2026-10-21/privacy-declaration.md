# 隐私保护指引填写稿与真实采集映射

日期：2026-10-21。本文依据当前源码和微信官方接口映射编写。**运营主体、真实联系渠道、保存期限和生效日期未核验；资料删除、单独同意及内容审核尚未实现。本稿不能直接作为已生效政策上传。**

## 两个后台入口分别核对

现网入口为“账号设置 → 服务内容声明 → 用户隐私保护指引”；提审入口为“管理 → 版本管理 → 提交代码审核 → 信息填写页面”。现网与提审隐私修改互不自动覆盖，提审被拦截时应在提审入口修改，不只改现网。[微信填写说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/)

提审时不得勾选“未采集隐私”。官方隐私弹窗可以由微信自动弹出；拒绝后调用失败必须正常处理，不能自动重复弹窗或绕过授权。`getPrivacySetting.needAuthorization=false` 同时可能表示后台未声明，因此不能作为“隐私配置已正确”的证据。[官方弹窗说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)、[getPrivacySetting](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/privacy/wx.getPrivacySetting.html)

| -------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 收集你的昵称、头像         | `chooseAvatar`、`input type="nickname"`；编辑资料                                    | 用于本人资料维护、活动报名身份识别及经单独同意的公开骑友名单和骑行名片展示                                       | 头像上传后云存储；昵称可手填。当前默认头像公开，单独同意未闭环                 |
| 收集你选中的照片或视频信息 | `wx.chooseMedia`、旧版本 `wx.chooseImage` 兼容；资料背景、活动、群二维码、俱乐部图片 | 用于由你主动选择的个人背景、活动说明图片、活动群二维码与俱乐部展示图片；上传前处理尺寸与格式                     | 只选图片，不采集视频；有归属/格式/摘要校验，无统一违规内容识别                 |

## 公开披露与受托/第三方处理

本人及审核管理员完整显示实名电话；其他骑友只见昵称，不返回实名或电话；头像及所选背景可公开；后援车司机电话完整公开。这是已确认的展示规则，但公开披露仍需取得信息主体的单独同意，提供撤回方式。[个人信息保护法第二十五条、第五十五条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

后台若默认生成“不会公开披露”，必须通过平台允许的填写方式及补充文档说明真实公开范围；不能保留与实际名单和名片冲突的承诺。

| 服务           | 实际用途与数据                                                                                          | 填写边界                                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 微信平台       | 身份、隐私授权、头像选择、文件/位置选择、订阅通知、剪切板等                                             | 以微信隐私规则为准；官方授权不自动替代业务公开披露的单独同意                                                                         |
| 腾讯 CloudBase | 云函数、数据库、云存储及临时媒体地址                                                                    | 核验实际受托服务主体、合同、区域和期限；不能把云服务写为不处理个人信息                                                               |
| Strava         | 管理员主动 OAuth，当前请求 `read`；返回 athlete ID/name、加密 access/refresh token，按路线 URL 导出 GPX | 不同步普通骑友的运动指标；不上传报名人姓名电话；管理员账户和路线资料仍属于真实第三方处理，需说明接收方、用途、撤销路径及适用跨境要求 |
| 微信内容安全   | 拟接入文本与图片审核                                                                                    | 当前尚未接入；实施后说明会提交需审核的公开文字、图片及对应微信标识，不上传与审核无关的实名、电话和紧急联系人                         |
| 微信意见反馈   | 拟增加官方反馈入口；平台后台收件                                                                        | 当前设置页未实现；上线后说明用户主动提交的内容/附件由微信处理，避免默认上传完整日志或私人资料                                        |

Strava 应用授权可以在 [Strava 应用设置](https://www.strava.com/settings/apps)撤销；仅删除本地记录不等于撤销 Strava 权限。现有服务端未实现撤销 action，也未取得目标环境撤销回读。[Strava 授权文档](https://developers.strava.com/docs/authentication/)

## 用户权益填写

已存在：本人查看和更正资料、删除/替换背景图、查看微信隐私说明、按次选择订阅。设置页的“清理缓存”只清可重建缓存，**不是资料删除或账号注销**。

待实施：设置页授权入口、官方意见反馈、明确的资料删除请求与状态、公开昵称/图片同意及撤回、Strava 撤销、删除补偿与合法保留反馈。

微信官方说明还包含“右上角 … → 设置 → 小程序已获取的信息 → 通知开发者删除”等适用入口；负责人须确认实际可用路径以及通知的接收和处理，不以文案说明代替闭环。[权益填写说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)

资料删除、复制、更正、撤回请求应在核验本人身份后处理；无法立即删除时说明原因、受限保留范围和后续处理，不能以进行中活动为由无限期拒绝法定请求。[个人信息保护法第十五、四十五至五十条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

## 保存期限与定稿条件

当前没有完整个人资料、报名记录、反馈和备份的自动保留期策略。媒体替换存在 24 小时回收安排、路线预览有技术有效期，但这些不能作为全部个人信息保存期限。**不直接填写固定“180 天”“永久”或“立即删除全部数据”等未经实现的承诺。**

负责人需确定并落地：

- 资料在服务存续期间的必要保存范围，撤回和删除后哪些字段停止使用、清除或受限保留。
- 已结束活动的报名、审核和安全记录保存期限、法律依据、访问人群与到期清理。
- 图片 staging/canonical、过期 URL、缓存、日志和备份的最长消除或到期周期。
- 公开披露及必要敏感/第三方处理的影响评估与记录；影响评估记录依法至少保存三年，该期限不是全部用户资料的保留期。
- 实际可接收的隐私/投诉联系人；用户可行使权利的渠道及响应期限。

《个人信息保护法》第十九条要求必要的最短保存期限；第四十七条规定保留或删除困难情形下停止除存储和必要保护之外的处理。具体承诺与实际云资源回读、工作流和运营能力一致后，方可定稿。[法律依据](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)
