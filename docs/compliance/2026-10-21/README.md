## 本轮确认的事实

- 用户已确认登录公众平台并准备联系渠道。工具读取登录会话后连续超时，桌面核验为持续空白页；账号主体类型、认证、备案、已选类目、隐私声明与反馈收件状态仍为**未核验**。不要求重复登录，也不把会话存在当成办理成功。
- 当前设置页具备官方隐私说明和安全缓存清理；资料删除与公开同意服务端已通过本地复审，客户端入口、官方反馈与统一内容安全检查尚未交付。
- 候选服务类目为“工具 → 预约/报名”，备案服务内容候选为“生活服务 → 工具”。两套分类分别办理；不能用备案服务内容替代小程序服务类目。
- 昵称、头像、可选背景照片存在公开展示；后援车司机姓名和联系电话完整公开。不能在隐私声明里填写“所有资料仅本人可见”或“无公开披露”。
- 微信官方接口映射将 `wx.setClipboardData` 列入剪切板项目。当前源码仅点击复制时写入，不调用 `wx.getClipboardData`。
- 手机号主要由用户手动填写。服务端保留微信动态手机号接口，但本轮运行页面没有 `open-type="getPhoneNumber"` 按钮；后台应按提审包扫描和实际使用核对，不把保留接口写成已运行流程。
- 内容校验现有能力只验证图片类型、摘要、归属和可信登记，不能当作违法违规内容识别。
