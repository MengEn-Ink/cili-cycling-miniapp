# PR341 缓存失效闭合验证

## 范围

本片闭合现有仓储与个人页缓存的并发失效边界：

- 仓储读取失效后，旧请求不能再从持久化缓存返回已撤销数据，也不能覆盖新请求。
- 个人页卡片缓存使用 revision 贯穿读取、图片保存和缓存提交。
- 资料更新、账号清理或媒体恢复触发失效时，旧卡片和已保存图片立即清理。
- 失效后迟到的图片保存结果会被回收，不再重新写入页面或磁盘。

本片不接入权益服务端 generation、删除事务、显式同意 UI、内容审核门槛或 Strava 运行状态机。

## TDD 与单测

单测生成严格完成 Step1 至 Step7。`TARGETS` 限定 `CachingRepository.readThrough`、`profile-page-cache` 和个人页唯一缓存消费者；`BUG_MAP` 确认 3 个 P1：

1. 失效前的持久化离线兜底可在旧请求失败后恢复。
2. 图片下载或保存失效后仍可返回旧映射或泄漏新文件。
3. 个人页迟到响应可重新应用旧资料并写回卡片缓存。
