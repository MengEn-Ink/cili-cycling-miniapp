# 俱乐部发现、详情与人数上限验收报告

- 日期：2026-10-18
- 分支：`feat/club-discovery-capacity`
- 范围：俱乐部首页、详情、新建、资料管理、头像补充与人数上限

## 验收结论

代码层验收通过。老用户首页使用右上角小型“＋ 新建”入口；新用户空态仍可浏览推荐和创建俱乐部；已加入俱乐部整卡进入详情。创建俱乐部要求头像和 2–10000 人上限，管理员可查看当前人数并扩容，但不能把上限降到当前 active 成员数以下。

服务端以 `member_count` 作为强一致容量计数：新俱乐部 OWNER 初始化为 1，公开加入只在创建新的 active membership 时自增，重复加入不重复计数，满员时拒绝。历史俱乐部缺少容量字段时，在权威事务内按 active memberships 回填；列表回填前显示“人数待同步”，不展示虚假容量。

## 验收路径

1. 从“我的”进入俱乐部首页，确认老用户右上角显示“＋ 新建”，新用户空态下推荐列表仍可见。
2. 点击已加入俱乐部卡片进入详情；管理员进入资料管理，验证头像、名称、城市、简介、加入方式和人数上限可编辑。
3. 新建俱乐部时不上传头像应被阻止；人数上限小于 2、大于 10000 或低于当前人数时应显示明确提示。
4. 对公开俱乐部执行正常加入、重复加入和满员加入，验证成员计数分别自增一次、保持不变和拒绝。
