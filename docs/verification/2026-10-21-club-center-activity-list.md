# 2026-10-21 俱乐部主页活动列表验收

## 目标

优化俱乐部主页的信息层级：封面只承担视觉表达，名称、城市、简介与身份进入稳定底色区域；移除主页中的唯一性技术话术，并在主页直接提供可进入详情的近期活动紧凑列表。

## 实现范围

- GitHub Pages 与微信小程序同步更新俱乐部主页布局、文案和三行近期活动列表。
- 俱乐部资料与活动请求并行启动、独立渲染；活动弱网或失败不阻塞主页主体。
- 活动失败支持独立重试，并以独立请求代际阻止迟到响应覆盖最新结果。
- Pages 活动行携带活动 ID，进入详情后展示对应活动的标题与集合地点。
- 设置页新增 `2026.10.21.2` 发布说明；云函数与数据结构未变更。
