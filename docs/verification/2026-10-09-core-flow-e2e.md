## 发现与处理

### 自动化页面时序

开发者工具自动化 SDK 在首屏 page meta 未建立时读取当前页面，会返回空元数据；页面跳转后立即读取也会把旧页面误判为目标页面。

处理：等待目标页面路径和业务数据同时满足条件，再判定跳转完成。

### 写操作超时后的未知结果

一次报名按钮调用出现自动化响应超时，但后续回读确认云端已写入 `pending`。如果直接重试，可能掩盖幂等问题或留下测试占位。

处理：超时后先按隔离活动标记和本人报名记录对账；发现写入成功后执行补偿取消，再结束活动。禁止盲目重试写操作。

### 重复提交语义

服务端对占位中的重复提交返回 `REGISTRATION_EXISTS`，而不是返回原记录。业务不变量仍成立：只有一条报名、报名 ID 不变、占位只增加 1。

处理：手册明确允许 UI 阻止第二次提交或服务端返回稳定重复错误，通过标准以业务不变量为准。
