# 2026-10-21 路线坐标与报名模式验收

## 目标

修复路线在腾讯地图中的坐标漂移，简化路线详情起点信息与导航入口；同时落地公开报名 / 审批报名双模式、活动日零点自动截止和报名详情按钮间距。

## 实现范围

- GPX 与公开路线预览保持 WGS84 事实数据，只在地图展示边界统一转换一次 GCJ-02。
- 微信地图选点保留 GCJ-02，不重复转换；轨迹、标记和视野点使用同一展示模型。
- 路线详情不再展示经纬度文本，起点仅保留地名与“导航到起点”快捷方式。
- 新活动默认公开报名，有名额时直接通过；审批模式仍进入待审核，缺字段的旧活动继续按审批模式处理。
- 满员统一进入候补；释放名额后按 FIFO 补位，并按活动报名模式决定直接通过或待审核。
- 创建与编辑页移除报名截止时间输入，服务端统一派生为活动开始日北京时间零点。
- 报名详情的两个操作按钮增加固定间距，避免贴合与误触。
- 设置页发布版本更新为 `2026.10.21.3`。

## 坐标系上线门禁

| 不变量 | 自动化保护 |
| --- | --- |
| GPX / 公开路线预览只转换一次 | `tests/route-analysis-runtime.test.ts` 覆盖两类来源；`tests/route-map-coordinate-invariant.test.ts` 阻断重复转换 |
| 微信选点不重复转换 | `preserveKeyPointIds` 跳过起终点选点，运行时用例核对 marker 与中心点 |
| 地图元素同源 | 断言 `polyline` 首点与 `include-points` 首点一致 |
| 禁止人工固定偏移 | 坐标门禁扫描并拒绝硬编码偏移方案 |
| 普通用户不显示经纬度 | 路线页面与 Pages 契约均断言不出现坐标字段 |

> 生产上线前必须在最新微信开发版中选取一条含明显道路转折的真实 GPX / 公开路线，核对轨迹贴合腾讯底图、起点 marker 与导航落点一致；该人工核对不得被自动化测试替代。若未完成，版本只允许停留在开发版，不得提交正式发布。
