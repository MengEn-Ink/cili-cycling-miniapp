## 发布方案

所有远端必需 checks 全绿、无未解决评审评论且 mergeable 正常后合并。仅由 GitHub Actions 执行 main CI 和微信开发版自动上传。无云函数或索引改动，应由累计部署决策安全跳过 CloudBase；若实际决策涉及额外历史变更则单独核对，不在沙箱直接部署。
