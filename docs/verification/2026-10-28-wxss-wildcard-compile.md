# 微信 WXSS 通配选择器编译修复验收记录

## 1. 验收对象

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-10-28 |
| 分支 | `fix/wxss-wildcard-compile` |
| 目标 | 修复微信上传阶段 WXSS 编译失败，并阻止业务样式再次引入通配选择器 |
| 影响范围 | 全局 WXSS、WXSS 契约测试、客户端版本与设置页更新日志 |
| 非影响范围 | 后端、接口、云函数、数据结构与正常视觉 |

## 2. 失败证据与根因

- `miniprogram-ci` 外层错误码为 `20003`，结构化内层错误码为 `-80056`，安全摘要为 `WXSS compilation failed`。
- `miniprogram/app.wxss` 的减少动态效果媒体查询使用了 `[data-v1-layout] *`、`*::before`、`*::after`。
- 原生微信 WXSS 不支持通配选择器；全仓业务 WXSS 检查未发现注释之外的其他存量通配选择器，因此本次只修复该处。

## 3. 修复与兼容策略

- 删除三个不兼容的通配选择器，改为 `view`、`text`、`button`、表单、媒体、滚动、地图等明确的原生标签选择器。
- 补充头像、品牌标识、状态、封面与文字动效等组件宿主类，使 `prefers-reduced-motion: reduce` 下的动画及过渡继续缩短至 `1ms`。
- 选择器只在减少动态效果媒体查询中生效；正常系统设置下不改变布局、配色、动效或交互。
- 新增 WXSS 契约测试：扫描 `miniprogram/**/*.wxss` 的选择器，禁止通配选择器；解析时忽略注释、声明中的乘号及属性值中的星号。

## 5. 回滚

无需变更或回滚后端、接口、云函数及数据。若需回滚客户端修复，可恢复 `miniprogram/app.wxss` 的减少动态效果规则，同时移除 `2026.10.28.2` 更新日志、版本号和 WXSS 契约测试；但恢复通配选择器会再次触发 `-80056`，回滚后不得执行微信上传，直至替换为兼容选择器。
