# Oil UI 全页面高信息密度适配验收

## 1. 验收对象

| 项目 | 内容 |
| --- | --- |
| 范围 | 小程序与 GitHub Pages 全局设计 Token、17 页面交互原型、设置页发布说明 |
| 客户端版本 | `2026.10.22.1` |
| 设计基线 | 2026-10-16 沸点设计稿，Oil UI 仅用于信息减法、状态反馈与渐进披露 |
| 后端范围 | 不涉及 API、云函数、数据库、索引和权限变更 |

## 2. 设计决策

- 页面边距由 32rpx 收敛为 28rpx，卡片间距由 28rpx 收敛为 20rpx，卡片内边距由 32rpx 收敛为 24rpx。
- 96rpx 主控件、字体、色彩、圆角、状态语义与原沸点布局保持不变。
- 通过分组、对齐和关键差异优先提高同屏信息量，不依靠缩小触控区域。
- Pages 新增覆盖 17 个正式页面的可点击方案，并从研发交付中心提供唯一入口。
