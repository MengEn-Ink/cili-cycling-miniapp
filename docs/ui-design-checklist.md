# 此里 UI 设计与验收清单

## A. 设计输入

- [ ] 明确核心用户、唯一主要任务与完成信号。
- [ ] 列出必须展示的事实、状态、动作和错误恢复。
- [ ] 指定复用的 Token、共享组件和相似页面。
- [ ] 写明页面 Override 及不能偏离的 Master 规则。
- [ ] 确认不修改的业务契约、权限和数据口径。

## B. 内容与信息架构

- [ ] 首屏回答“这是哪里、当前状态、下一步做什么”。
- [ ] 一个视口只有一个主要操作，次要操作降级但仍可发现。
- [ ] 关键数据带单位、时间或有效期，地图与图表来源一致。
- [ ] 长中文、空值、超长昵称和未知状态不会破坏布局。
- [ ] 未接入能力不显示占位技术词、假数据或误导入口。

## C. 视觉与组件

- [ ] 颜色、圆角、间距、控件高度来自 `docs/design-contract.json`。
- [ ] 标题、正文、辅助文字和关键数字层级清晰。
- [ ] 主按钮、次按钮、文字按钮和可点击卡片职责明确。
- [ ] 默认、按压、禁用、加载、空、错误和成功状态齐全。
- [ ] 图片有占位与恢复，地图/海拔/海报不遮挡主操作。

## D. 小程序平台

- [ ] 使用原生 WXML/WXSS、`rpx`、`hover-class` 和支持的能力。
- [ ] 不依赖 DOM、`:hover`、Web 字体或复杂浏览器选择器。
- [ ] 固定区域适配安全区，键盘和弹层不会遮挡表单或按钮。
- [ ] 340–390px 窄屏、低端设备和弱网下仍可完成任务。
- [ ] 微信开发者工具与真机都验证关键旅程。

## E. Pages 平台

- [ ] 使用语义 HTML、键盘焦点和相对资源路径。
- [ ] 支持 `prefers-reduced-motion`，动画可关闭且不承载唯一信息。
- [ ] 固定导航不遮挡锚点；表格窄屏可滚动。
- [ ] 图片为 WebP、尺寸明确、中文 alt、正文图按需懒加载。
- [ ] 页面从研发交付中心可达，不是孤岛页面。

## F. 可访问性与隐私

- [ ] 正文和控件对比度满足 `docs/design-contract.json`。
- [ ] 触控目标不小于 44px / 88rpx。
- [ ] 状态不只依赖颜色，错误说明恢复动作。
- [ ] 可点击非按钮元素有 role、aria-label 和键盘等价行为（Pages）。
- [ ] 页面只展示角色有权看到的实名、电话、头像和媒体。

## G. 自动化与证据

- [ ] `npm run test:design`
- [ ] `npm run check:design`
- [ ] `npm run test:ui-sync`
- [ ] `npm run check:ui-sync -- --strict`
- [ ] `npm run validate`
- [ ] `npm run coverage`
- [ ] `npm run audit:all`
- [ ] `git diff --check origin/main...HEAD`
- [ ] 更新 `docs/ui-sync-manifest.json`、双端截图和验收报告。
- [ ] 产品 UI 变化时更新设置页版本说明。

## H. 交付

- [ ] 相对最新 `origin/main` 只有一个中文提交，包含 Aime trailer。
- [ ] PR 八段描述、文件数、行数、测试和 head SHA 与最终 Diff 一致。
- [ ] PR checks、main CI、CodeQL 全绿。
- [ ] GitHub Pages、CloudBase 变更范围和微信开发版逐项核验。
- [ ] 正式页面和关键资源已在线回读，无控制台资源错误。
