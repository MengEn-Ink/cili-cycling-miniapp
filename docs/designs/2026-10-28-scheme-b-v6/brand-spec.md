# 此里 · 方案 B v6 品牌基线

日期：2026-10-28（Asia/Shanghai）

## 资产来源

- 品牌名称、字标与标志资产来自本仓库 `miniprogram/assets/brand/` 与 `docs/brand/logo-materials/`。
- 视觉比例、颜色和版式以用户提供的方案 B v6 `app.jsx`、`styles.css` 与 17 张效果图为准。
- 不重绘、不拉伸、不替换为第三方标志；微信系统胶囊与状态栏由平台原生渲染。

## 核心视觉

- 页面底：暖奶白 `#fbf5ea`。
- 抬升面：浅米色 `#f5ecd9`。
- 主文字：炭黑 `#211f1c`；次级文字使用可读的棕灰层级。
- 品牌动作：砖红 `#c0321f`；成功为森林绿，提醒为加深琥珀色。
- 影像区可使用近黑影院底，但浅色正文必须满足正常字号的可读性要求。
- 中文标题使用仓库既有宋体回退，正文使用系统无衬线；不得引入远程字体。

## 形态约束

- 小圆角、细边框、低阴影；避免重新回到大圆角卡片套件。
- 以内容密度和编辑式分隔组织页面，红色只用于主动作、选中态和明确危险/异常。
- 实际点击区域至少 44px；视觉按钮可以更小，但命中区必须扩展。
