## 实施交接

先迁移双端令牌与公共组件，再依规格推进现有 13 页。保持大字号、呼吸感、浅色可读性和实际 44px 触控范围，不新增业务功能或数据库字段；手稿未画出的现有入口和状态不得直接删除。

原稿中浅占位文字、部分控件边界与小号图标的视觉尺寸仍须在实施阶段修正。正文对比度至少 4.5:1，交互控件边界至少 3:1，实际热区至少 44px；长页、安全区、完整电话与编号、340px 窄屏和系统字体放大需独立核对。

本人和审核管理员完整显示实名与电话；其他骑友只见昵称；后援车司机电话公开完整显示。静态示例与运行时权限必须分开验证。

实施完成后通过 `check:design`、`check:ui-sync -- --strict` 和全量 `validate`，采集绑定实际内容摘要、注明状态与脱敏范围的 13 页双端新主题证据，核验部署与物理真机完整旅程。只有部署并验收通过后，才能移除高优待办。
