# 此里 · 骑行影像志

方案 C 的完整设计提案，经后端能力核对后修订，包含 16 个主业务页面与 12 个关键状态。「我的」头像与背景共同组成骑行名片，不再独立展示名片页面。

- [完整评审入口](index.html)：交互预览、16 页全览、状态与设计细节；默认打开「我的」。
- [可编辑设计画布](骑行影像志.design)：28 个自然长屏与摄影素材。
- [后端能力与设计细则](backend-capability-map.md)：字段、权限、真实状态与落地约束。
- [设计说明](../../superpowers/specs/2026-10-22-cycling-image-journal-design.md)。
- [校验记录](verification.md)。

用浏览器直接打开 `index.html`，或在本目录启动静态服务器。页面、摄影、字体和演示脚本可以离线使用。评审入口中可切换 340 / 375 / 430px，点击页面链接浏览业务流程。

手机外的评审场景选择器可查看普通成员／平台管理员、审核／公开／候补报名和签到状态。设计使用合成人物、不可拨打的演示号码及路线示意；所有操作只提供本地演示反馈，不连接真实账号与云环境。

`shared.css` 为共享样式，页面内嵌同一套样式与媒体，以兼容设计画布。`page-manifest.json` 为页面职责清单，`assets/sources.json` 为新生成摄影的来源记录。

生产仍为17条路由，此交付不改变生产 UI。背景移除与整表保存的后端冲突已记入高优清单P1；本稿不演示该操作成功。本稿不作为双真机或完整写链路验收证据。
