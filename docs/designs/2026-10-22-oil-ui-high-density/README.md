# 此里全页面 Oil UI 高信息密度交互方案

本方案在 2026-10-16“沸点”设计稿布局基础上，对小程序 17 个正式页面进行全量适配。Oil UI 仅用于信息减法、状态反馈和渐进披露，不改变此里的品牌与页面结构。

## 覆盖范围

- 骑友发现与报名：活动发现、活动详情、路线分析、报名表单。
- 行程与身份：我的行程、出发凭证、个人主页、资料编辑、设置、能力说明。
- 俱乐部：唯一俱乐部中心。
- 组织与审核：活动管理、活动编辑、报名审核列表与详情、俱乐部申请列表与详情。
- 状态：正常、加载、空、失败、弱网及页面特有业务状态。

## 密度原则

1. 通过分组、对齐和差异优先提高密度，不通过缩小触控区域提高密度。
2. 页面边距由 32rpx 收敛为 28rpx，卡片间距由 28rpx 收敛为 20rpx，卡片内边距由 32rpx 收敛为 24rpx。
3. 主控件仍保持 96rpx，状态不只依赖颜色，失败路径必须给出恢复动作。
4. 不新增后端接口、字段、权限或未接入能力。
