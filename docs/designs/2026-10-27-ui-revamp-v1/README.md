# UI 改版 V1 方向稿

本目录归档 2026-10-27 UI 改版的方向对比与裁决证据。正式组合方向为：

- B「内容先行」作为全部 17 路由的统一设计语言；
- 活动详情额外吸收 C「全宽摄影 + 上浮白色 sheet」；
- 管理与表单页面在 B 的 token、字阶、间距与组件体系内采用 A「稳健精修」的结构策略，不保留旧式裸样式。

[打开三案对比](ui-directions.html)。完整约束见 [UI 改版 V1 设计规格](../../superpowers/specs/2026-10-27-ui-revamp-v1-design.md)。

方向稿沿用仓库已有设计摄影，只比较视觉层级和组件语言，没有新增生产字段、假头像或运行时数据。示例文字用于呈现已有字段的排版边界，不会写入产品。

本目录不是实现截图、微信开发者工具证据或 Task 0 视觉基线。逻辑目标虽然是 iPhone X 375×812，但 PNG 实际尺寸必须在目标主机通过 PNG header 实测后才能冻结；390 宽模拟器截图只作功能巡检。
