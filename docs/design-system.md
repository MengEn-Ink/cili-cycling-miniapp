# 此里统一设计规范

状态：正式基线，2026-10-16。适用于 `app.json` 全部 13 页、共享组件和 Pages。结构与交互以当前 Pages 为参照，变量与可读性以 [design-contract.json](design-contract.json) 为机器可校验标准。历史主题文档仅保留决策背景。

## 色彩与可读性

| 用途 | 变量 / 色值 | 约束 |
| --- | --- | --- |
| 页面 / 卡片 | `--color-bg` `#f3f3f1` / `--color-surface` 白 | 只使用浅色主题 |
| 正文 / 辅助 | `#171717` / `#666666` | 正文与实际背景至少 4.5:1；现有正文维持 7:1 以上 |
| 主操作 | `--color-action` `#c84320`，白字 | 对比度 4.91:1；按下态 `#a93619` |
| 品牌强调 | `--color-brand` `#e85b32` | 线条、装饰、当前步骤；上方文字使用近黑色 |
| 媒体承载区 | `#171717`，白字 / `#d4d4d4` 辅助字 | 照片上的文字必须有深色承载层 |
| 成功 / 提醒 | 绿色 / 深金色加浅背景 | 同时出现图标或文案，不只依赖颜色 |
| 卡片边线 / 控件边线 | 浅灰 / 近黑 | 卡片线是分组装饰；输入控件边界至少 3:1 |

此次保留最新版 Pages 的橙色主操作方向，将原 `#e85b32` 白字（3.52:1）校准为深橙。旧规范的黑色 CTA 和 2px 黑卡片边线不再作为验收标准。不得为了对齐截图恢复低对比配色。

## 控件与布局

- 主按钮深橙白字，次按钮白底深字；每个区域有明确主次操作。禁用态使用灰底深字，禁止整体透明化。
- 文字按钮、删除、缩略图操作也要显式指定背景。原生微信 `button` 默认背景不可假定为透明；图片删除采用近黑底白字。
- 按钮与分段控件基准高度 44 CSS px / 88rpx。窄屏按实际计算尺寸检查，必要时使用 `min-height:44px`；视觉尺寸不等于实际触控范围。
- 375px 设计宽度下 `2rpx = 1px`。卡片半径 14px，控件半径 10px，页面边距 24px，卡片间距 16px。340px 下使用 16px 页边距及单列退化。
- 输入框显式使用正文色、白色背景、可见边线与 `input-placeholder`；错误信息就近展示，使用可读深橙与文字。
- 固定操作栏预留正文底部空间并加 `env(safe-area-inset-bottom)`。最后一个可交互元素必须可滚动到操作栏上方。
- 大标题、长标题和时间允许换行；数字保持等宽排列。集合日期与自然时间分开呈现。
- 照片、路线 Canvas、空图提示与错误重试都需核验。不得把缺图误记为视觉通过。

## 数据与状态

每页至少核对正常态及一项关键状态（空、失败、禁用、已报名、审核状态或表单错误）。普通骑友只见昵称；本人和审核管理员完整显示实名和电话；后援车司机电话公开完整显示。公开证据须移除真实资料与二维码。

Pages 使用演示样本，模拟器使用云端数据；允许不同的标题、人数和图片，但须在截图清单记录差异。注入合成数据的截图标为 `fixture`，脱敏后的真实截图标为 `sanitized-runtime`，均不得冒充真实写链路或权限验证。

## 门禁与变更流程

1. 修改设计前核对本文与 Pages 对应路由和状态；变更变量时同步契约、WXSS、CSS及关联测试。
2. `npm run check:design` 校验 32 个双端变量与 15 组对比度；通过 `validate` 进入 CI。
3. `npm run test:devtools:e2e` 验证真实云端只读数据、页面和媒体，失败也保存报告；结果明确包含未覆盖范围。
4. `npm run check:ui-sync -- --strict` 校验全路由双端 PNG、同视口、状态说明及内容摘要。v2 摘要绑定被截图的内容，不要求在截图中预知最终 squash SHA。
5. 人工按同视口截图核验层级、文本、控件、触控、安全区。清单中 `differences` 或 `blocked` 须在验收记录解释，不等于视觉全量通过。
6. 合并后核对 main CI、Pages、开发版上传，再运行同版本模拟器。iOS / Android 物理真机完整 UAT 独立记录；只有部署与验收都完成才能关闭高优清单。

静态对比度门禁不模拟所有 CSS 层叠和照片亮度，PNG 存在也不证明截图正确。运行截图和真机核对是必要补充。完整操作见 [E2E 手册](verification/wechat-devtools-e2e.md)。
